Privacyverklaring

wijkwarm.nl is een dienst van Klaasystems, gevestigd in Nederland, te bereiken via info@klaasystems.nl. Deze pagina beschrijft welke gegevens we verwerken. Dat zijn er weinig, omdat de site uit vaste pagina's bestaat zonder accounts.

Wat we niet doen

We plaatsen geen eigen cookies, we volgen je niet over andere sites en we verkopen geen gegevens. De rekenhulpen en checks op de pagina's werken volledig in je browser; wat je invult, verlaat je apparaat niet.

Hosting

De site wordt gehost bij GitHub Pages (GitHub, Inc.). GitHub verwerkt bij elk bezoek je IP-adres in serverlogboeken om de site te kunnen leveren en beveiligen. Zie de privacyverklaring van GitHub.

Lettertype

De koppen gebruiken het lettertype Archivo via Google Fonts. Bij het laden ziet Google je IP-adres. Google gebruikt dat volgens eigen opgave niet om je te volgen.

Offertes via partners

Op sommige pagina's staat een knop om offertes aan te vragen. Die knop leidt naar een partnersite, waar je zelf gegevens invult. Vanaf dat moment geldt de privacyverklaring van die partner. Wij ontvangen een vergoeding als je via onze knop offertes aanvraagt, maar we zien je gegevens niet. De link bevat een code waarmee de partner weet dat je van wijkwarm.nl komt.

Advertenties

Als we advertenties tonen, gebeurt dat via Google AdSense. Google kan dan cookies plaatsen. Zolang er geen advertenties op de site staan, gebeurt dit niet.

Je rechten

Je kunt inzage, correctie of verwijdering vragen van gegevens die we van je hebben, via het mailadres hierboven. We reageren binnen een maand. Klachten kun je ook indienen bij de Autoriteit Persoonsgegevens.
